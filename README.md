# Student Clubs

Веб-приложение для каталога студенческих кружков и управления ими. Студенты находят кружки и записываются на занятия; преподаватели ведут свои кружки; администратор управляет пользователями и категориями.

## Запуск

### Требования

- Docker Desktop с Docker Compose plugin (Compose v2.24.0 или новее).
- Windows PowerShell для команды проверки ниже; приложение также запускается в Docker на других системах.
- Для локального запуска не требуются отдельно установленные Python, Node.js или PostgreSQL.

Образы Python, Node.js, Nginx, PostgreSQL и MinIO закреплены по digest в Dockerfile/Compose. Frontend-зависимости устанавливаются по lock-файлу; backend-зависимости закреплены в `backend/requirements.txt`.

### Установка и запуск на чистом клоне

В PowerShell из корня репозитория выполните:

```powershell
Copy-Item backend\.env.example backend\.env
docker compose up -d --build
.\scripts\check-health.ps1
```

Это три команды. Если `backend\.env` уже существует, не перезаписывайте его: проверьте, что в нём заданы локальные настройки из `backend\.env.example`. Значения в примере предназначены только для разработки. Не используйте их в опубликованном окружении; задайте отдельный `SECRET_KEY` и учётные данные хранилища.

- Приложение: [http://localhost/](http://localhost/)
- API и Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)

### Проверка основного сценария

1. Выполните `.\scripts\check-health.ps1`. Скрипт проверяет UI, health endpoint backend и каталог кружков через прокси frontend; каждый запрос должен вернуть HTTP 200.
2. Откройте приложение, войдите под локальной учётной записью преподавателя (`teacher` / `teacher123`) и создайте кружок. Эти демонстрационные учётные данные создаются при инициализации БД и предназначены только для локального запуска.
3. Зарегистрируйте отдельного студента, откройте созданный кружок, запишитесь на него и проверьте результат в профиле студента.

Для остановки контейнеров выполните `docker compose down`. Данные PostgreSQL и MinIO хранятся в Docker volumes и сохраняются после остановки.

## Разработка и тесты

Для backend нужны Python 3.12 и зависимости из `backend/requirements.txt`; для frontend — Node.js 20 и npm.

- Backend: из `backend/` установите `python -m pip install -r requirements.txt`, затем `python -m pytest -q`.
- Frontend: из `frontend/` выполните `npm ci`, затем `npm test`.
- Frontend lint/build: `npm run lint` и `npm run build`.
- End-to-end: `npm run test:e2e` (нужен запущенный проект и установленный браузер Playwright).

Подробности окружения и фактическое состояние CI приведены в [`docs/04-testing.md`](docs/04-testing.md). Сборка, выпуск и развёртывание описаны в [`docs/05-deployment.md`](docs/05-deployment.md).

Исходный репозиторий: [KilloQ/StudentsClubs](https://github.com/KilloQ/StudentsClubs). Проект написан автором репозитория; это не форк, upstream не используется.
